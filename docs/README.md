# Documentation Index

Companion technical documentation for the ESM-MSR evaluation benchmarks, dataset splitting, cross-set homology and training-data overlap audits, and epistasis metrics.

---

## Documents

| Document | Description |
| :--- | :--- |
| [`BENCHMARKS_OCT2026.md`](BENCHMARKS_OCT2026.md) | Comprehensive evaluation tables comparing ESM-MSR against retrained baselines (MutateEverything, ThermoMPNN / ThermoMPNN-D, SPURS / SPURS multi) and published zero-shot/supervised predictors across 12 external $\Delta\Delta G$ datasets, the homology-restricted Tsuboyama MegaScale split (`splits_oct06_capped`), 7 functional DMS assays, Domainome (522 domains), and ProteinGym (213 DMS assays), with per-cell training-data overlap annotations. |
| [`LEAKAGE_AUDIT_OCT2026.md`](LEAKAGE_AUDIT_OCT2026.md) | Methodology, reconstructed training inventories, split-boundary verification, and row-level sequence/structural overlap findings across all evaluated models and 3.53 million benchmark variants (`analysis/leak_audit/run_all.py`). |
| [`SPLITTING_AND_HOMOLOGY_AUDIT.md`](SPLITTING_AND_HOMOLOGY_AUDIT.md) | Procedure, thresholds, tools, sensitivity analysis, and assumptions for the five-stage `splits_oct06_capped` MegaScale split (`preprocessing/split_tsuboyama.py`) and the coverage-tiered MMseqs2 + Foldseek homology pipeline. |
| [`validation_metrics.md`](validation_metrics.md) | Mathematical definitions and implementation details (`src/esm_msr/epi_metrics.py`, `src/esm_msr/val_stats.py`) for ESM-MSR dual-pass readouts, the closed-form Tobit observation link, $\Delta\Delta G$ ranking metrics, and the four-level $\Delta\Delta\Delta G$ epistasis hierarchy. |
| [`INFERENCE_RESOURCES.md`](INFERENCE_RESOURCES.md) | Inference cost of one run per model type on the full benchmark in a fixed gpu4 slot (RTX A4500, 6 CPUs, 60 GB): wall hours per benchmark group, peak host RAM and GPU memory, failures; generated by `analysis/scoring/resource_summary.py --docs`. |
