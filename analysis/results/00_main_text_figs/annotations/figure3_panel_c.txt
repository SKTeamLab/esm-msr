Figure 3, Panel c — ProteinGym per-assay delta-rho by functional property across sigma = 0.5 and 1.0
=====================================================================================================

Per-assay Spearman's rho change (delta-rho = rho(sigma) - rho(sigma = 0)) across the five ProteinGym coarse functional categories (Activity, Binding, Expression, Organismal fitness, Stability) comparing ESM-MSR at sigma = 0.5 and sigma = 1.0 against ESM3-small-open (sigma = 0, adapters off), using the deployed readout (Dual-view combined head on multi-mutant assays, WT head on single-mutant assays). Each dot represents one assay; thin grey 'x' markers show assays homologous to the training set (plotted for completeness but excluded from boxes, medians, means, header counts, and p-values). Boxes show the interquartile range (IQR), thick horizontal lines show medians (with numerical values), and thin horizontal lines show means. P-values below the x-ticks are two-sided joint assay x seed bootstrap tests of H0: mean delta-rho = 0, Holm-adjusted across the 10 category x sigma comparisons.
