Figure 1, Panel c — Homology-Restricted MegaScale double mutants: additive vs epistatic scoring
===============================================================================================

Mean per-domain Spearman's rho on double mutants from the Homology-Restricted MegaScale test set (n = 13,319 double mutants across 13 test domains), comparing additive scoring (sum of single-mutant model predictions, hatched bars) against epistatic scoring (direct double-mutant model prediction, solid bars). Retrained models average 3 training seeds; error bars show 95% domain x seed bootstrap confidence intervals. Brackets report paired one-sided domain x seed bootstrap p-values (B = 10,000) testing H1: rho_epistatic > rho_additive.
