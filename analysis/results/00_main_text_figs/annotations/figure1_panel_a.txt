Figure 1, Panel a — ESM-MSR dual-view architecture, calibration, and supervision
================================================================================

Schematic of the ESM-MSR architecture and training/inference pipeline built on the frozen 1.4B-parameter ESM3-small-open backbone with wild-type (WT) backbone coordinates encoded via the frozen ESM3 VQ-VAE structure tokenizer. Two asymmetric LoRA adapters attach to the shared transformer backbone: a low-rank WT adapter (rank r = 2, alpha = 4; single forward pass per protein with cached L x 20 logits) and a higher-rank mutant (MT) adapter (rank r = 16, alpha = 16; one forward pass per multi-mutant variant). Site log-odds sums (x = sum_{i in mut} [l_i(mut) - l_i(wt)]) are mapped to stability changes via per-mutation linear calibration (s * x + n * b, with s > 0), producing exact additive single-mutant predictions (ddG_WT) and dual-view ensemble multi-mutant predictions (ddG_AB = 0.5 * (WT + MT)), from which predicted epistasis is dddG_AB = ddG_AB - (ddG_A + ddG_B). Both views are supervised with assay-floor-aware Tobit NLL + ListMLE ranking losses using posterior teacher forcing on multi-mutants.
