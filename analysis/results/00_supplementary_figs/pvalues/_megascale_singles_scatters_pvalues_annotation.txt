Statistical Annotation: _megascale_singles_scatters_pvalues.csv
==================================================
Figure: Supplementary Figure (_megascale_singles_scatters) — Homology-Restricted MegaScale test single mutants (n = 35,421, 33 domains).

Metrics Tested:
  Pooled Spearman's rho, pooled Pearson's r, and pooled RMSE (kcal/mol) across all 35,421 variants, matching the seed-mean summary statistics shown in each scatter panel.

Statistical Test & Resampling Procedure:
  Paired nonparametric domain-cluster x training-seed bootstrap (B = 10,000, deterministic seed).
  All 33 test domains are resampled identically across models via shared Multinomial(33, 1/33) cluster weights, jointly with Multinomial(3, 1/3) seed weights for 3-seed retrained models.
  One-sided Phipson & Smyth (2010) p-value: p = (1 + #{b : delta_favoring_msr^(b) <= 0}) / (B + 1).
  Bonferroni correction adjusts within each metric over all m = 8 clean comparator models.
  `all_clean_IUT` gives Berger's (1982) Intersection-Union Test (p_IUT = max_j p_j).
